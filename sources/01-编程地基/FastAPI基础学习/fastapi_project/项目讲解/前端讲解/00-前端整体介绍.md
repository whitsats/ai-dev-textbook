# 前端整体介绍（Vue3 + Vite）

> 对应前端目录：`fastapi_project/frontend/`

## 1. 前端项目做什么
前端是一个“文章分享/浏览”站点，配合 FastAPI 后端实现：
- 首页文章列表（栏目筛选、搜索、分页）
- 文章详情（收藏、评论、回复）
- 登录/注册（图形验证码 + 邮箱验证码）
- 写文章/编辑文章（草稿、发布、上传头图）
- 个人中心（我的文章/收藏/评论）

## 2. 技术栈与依赖
`frontend/package.json` 显示：
- 构建：Vite
- 框架：Vue 3
- 路由：vue-router 4
- 请求：axios

## 3. 目录结构
核心目录：
- `frontend/src/main.js`：入口，创建 app 并挂载 router
- `frontend/src/router/index.js`：路由定义与路由守卫
- `frontend/src/views/`：页面（每个 .vue 基本对应一个路由页面）
- `frontend/src/components/`：可复用组件（当前主要是 `Header.vue`）
- `frontend/src/api/`：后端 API 封装（按业务模块分文件）
- `frontend/src/utils/`：工具（token、本地存储、axios 实例与拦截器）

## 4. 入口与启动流程
入口：`src/main.js`
- `createApp(App)`
- `app.use(router)`
- `app.mount('#app')`

这意味着：
- App 是顶层壳组件
- router 决定页面切换与 URL 规则

## 5. 路由结构与鉴权
路由文件：`src/router/index.js`

路由表（简化）：
- `/` -> `Home.vue`
- `/login` -> `Login.vue`
- `/register` -> `Register.vue`
- `/article/detail/:id` -> `ArticleDetail.vue`
- `/article/edit` -> `ArticleEdit.vue`（requiresAuth）
- `/personal` -> `PersonalCenter.vue`（requiresAuth）

### 5.1 Hash 路由
router 使用 `createWebHashHistory()`：
- URL 类似 `/#/login`
- 适合纯静态部署，后端无需额外配置 history fallback

### 5.2 路由守卫
`beforeEach`：
- 访问需要登录的页面（meta.requiresAuth）时，若 `!isLoggedIn()` 则跳转登录页
- 并携带 redirect 参数：登录后可跳回原页面（当前登录页代码默认 push `/`，后续可优化成按 redirect 跳回）

## 6. 登录态（token）存储与读取
工具文件：`src/utils/auth.js`
- token 存在 localStorage：key=`fastapi_token`
- `isLoggedIn()` 通过是否存在 token 判断
- `removeToken()` 会同时清理 `user_info`

## 7. 请求封装（axios）与拦截器
请求实例：`src/utils/request.js`

### 7.1 baseURL
- `baseURL: '/api'`

含义：
- 前端请求路径例如 `request({url:'/'})` 实际请求到 `/api/`
- 结合后端路由：`GET /api/` 对应首页数据接口

### 7.2 请求拦截器：自动加 Authorization
- 若本地存在 token：
  - `config.headers.Authorization = 'Bearer <token>'`

对应后端鉴权依赖：
- `backend/app/dependencies/current_user.py` 从 `Authorization: Bearer <token>` 读取

### 7.3 响应拦截器：统一处理未登录
- 若业务返回 `res.code === 401` 或 HTTP status=401：
  - `removeToken()` 清 token
  - 强制跳转 `/#/login`

## 8. API 模块与后端接口对应
`src/api/*.js` 约定：
- 每个文件对应一类后端模块
- 只负责封装 url/method/params/data

例：
- `api/article.js` -> `/article/*`
- `api/user.js` -> `/user/*`
- `api/comment.js` -> `/comment/*`
- `api/favorite.js` -> `/favorite/*`
- `api/personal.js` -> `/personal/*`

## 9. 顶部导航（Header 组件）
组件：`src/components/Header.vue`
- 始终显示：首页
- 已登录显示：写文章、个人中心、退出
- 未登录显示：登录

退出流程：
- 调用后端 `/user/logout`（即使失败也继续）
- 清理 token
- 跳回首页并刷新

## 10. 页面清单（views）
当前 `src/views` 有 6 个页面：
- `Home.vue`：首页文章列表
- `ArticleDetail.vue`：文章详情 + 收藏 + 评论/回复
- `ArticleEdit.vue`：写文章/编辑文章 + 草稿 + 上传头图
- `Login.vue`：登录（图形验证码）
- `Register.vue`：注册（邮箱验证码）
- `PersonalCenter.vue`：个人中心
