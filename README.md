> 一本面向在校生与转行求职者的 AI 应用开发教材。以「找一份 AI 应用开发 / 大模型应用 / 后端开发岗」为目标，
> 从 Python 与 FastAPI 地基出发，经过 AI 编程工具链、大模型与 Agent 原理、LangChain / LangGraph 框架、
> RAG 与生产级工程，最终落到简历、项目讲述与面试题库。

## 这本书解决什么问题

市面上的 AI 学习资料常见两种毛病：

1. **散**：PDF、笔记、题库各说各话，学完不知道知识点之间什么关系，更不知道面试会问到哪一层。
2. **飘**：上来就讲 Agent、讲 RAG，读者连一个能跑的后端接口都没写过，代码抄下来也不知道为什么这么写。

本教材的做法是：**先把资料拆成最小知识点，再按「地基 → 工具 → 原理 → 框架 → 系统 → 求职」重新排列**，
并让**同一个项目贯穿全书**（见 [`STYLE.md`](STYLE.md) 第五节），最后把面试题库按知识点打散嵌回各章。

## 素材库重建方式

原始资料已完整归档且未做任何修改，素材库可随时从原件重新生成：

```bash
cd 学生就业AI开发教材

python tools/extract_sources.py --report   # 只统计文本密度，不写文件
python tools/extract_sources.py            # 重建 sources/ 与 sources/README.md
```

依赖：`pdftotext`（poppler）、Python 3.10+。脚本行为见文件头注释。
