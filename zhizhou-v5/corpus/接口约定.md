# 知舟接口约定

## 写接口一律带 Idempotency-Key

所有写接口（POST / PATCH / PUT / DELETE）都必须携带 `Idempotency-Key` 请求头，
取值由调用方生成，同一业务动作重试时必须复用同一个值。
网关按这个值去重，重复请求返回第一次的结果，不重复执行。

## 错误码

| 码 | 含义 | 出现在 |
| --- | --- | --- |
| 6001 | 越权：调用方无权操作该资源 | 工具层 |
| 6002 | 限额：词元或频次超限 | 网关 |
| 6003 | 注入拦截：输入被护栏拦下 | 护栏层 |
| 6004 | 引用失效：答案里的引用编号指不到资料 | 生成层 |

这四个码只出现在 JSON 体的 `code` 字段里，HTTP 状态码一律 200。
