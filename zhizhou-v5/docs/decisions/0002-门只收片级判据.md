# ADR-0002 回归门与验收的主判据只收片级，不收文档级

- **状态**：已决定
- **背景（当时手上的那个数）**：四个配置的文档级命中率**逐个相同**：
  `recall.bm25=1.0`、`recall.vector=1.0`、`recall.hybrid=1.0`、`recall.rewrite=1.0`
  —— 六份文档、`k=3` 时这个读数已经饱和，它**没有分辨率**。
  换成片级才分得开：`span.vector=0.7222` 对 `span.hybrid=0.8333`。
  分辨率本身是 `app/metrics.py` 的 `min_detectable()` 给的 1/n，`cases=24` 时约为 0.0417。
- **决定**：回归门（5.6）与验收清单（5.8）的主判据建在**片级**；文档级命中率只留作粗筛，
  出现在报告里但不作为门的判据。
- **被否掉的选项及否掉的理由**：
  - 用文档级命中率当回归门：四个配置全是 1.0000，于是**任何改动都是「没有退步」**——
    一个永远通过的判据比没有判据更坏，因为它会被当成已经守住了；
  - 通过调小 `k` 或删题来制造分辨率：那是**改题**（改了尺子），不是改门；
    门的分辨率应当随题数变化而被记录，不该被反向设计。
- **失效线（什么条件下该推翻它）**：语料规模扩大后文档级不再饱和时，两个判据同时看；
  题集条数变化时必须重算 1/n（`cases` 不再是 24 时，0.0417 这个数就作废）。
