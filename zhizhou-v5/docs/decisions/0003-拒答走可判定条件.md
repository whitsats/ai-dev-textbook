# ADR-0003 拒答先判档、后生成，判据必须是可判定的条件

- **状态**：已决定
- **背景（当时手上的那个数）**：拒答四格是 `refusal.plain.right_refuse=3`、
  `refusal.plain.missed=1`、`refusal.plain.over=0`（四格表里另有一行是「模型自称与绑定不符」）。
  阈值扫描 24 个窗口 `sweep.windows_with_zero=0` —— **没有一个窗口能把误差压到 0**，
  最好的那一档仍有 `sweep.best_errors=1`。
  这两条合起来说明：拒答**不是调阈值能解决的问题**，缺的是一套能分开「漏拒」与「误拒」的判据。
- **决定**：拒答由两条**可判定**的条件给出（检索分档 ＋ 片级复述），返回**理由**而不是布尔；
  四格里的「漏拒」与「误拒」任何时候都分开报——它们要修的位置完全不同。
- **被否掉的选项及否掉的理由**：
  - 让模型自己回答「不知道」：它把「我不确定」当成了拒答，四格表里表现为
    **误拒上涨而漏拒不动**；模型的自我报告不能当判据，只能当一个被观测的对象；
  - 把两条判据合成一个布尔：5.8 的验收清单因此错报过一次 ✖——
    「发出去的答复对不对」与「模型自称的编号对不对」是两件事，合并必然在某天把合格的判成不合格。
- **失效线（什么条件下该推翻它）**：`sweep.windows_with_zero=0` 这条读数在语料或题集变化后
  必须重扫；一旦出现「某个窗口误差为 0」或线上分布与评测集明显不同（学校场景与真实企业语料），
  阈值与判据都要重定。
