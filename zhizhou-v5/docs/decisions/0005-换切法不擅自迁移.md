# ADR-0005 换切法不擅自迁移：迁移是一次发布动作，不是重构

- **状态**：已决定（迁移这件事**待定**，见失效线）
- **背景（当时手上的那个数）**：现状（段落切）的片级读数是 `span.hybrid=0.8333`，
  而可检测最小差异是 **1/24 ≈ 0.0417**（`cases=24`）——**小于它的差值不叫提升，叫噪声**。
  5.8 的三套库对照里，迁到结构感知切报出 +0.0556，刚过分辨率；
  而它同时意味着 5.1–5.7 七章正文里**每一个片级读数都作废**。
- **决定**：迁移按**发布动作**处理：先重取基线、重扫阈值表、把要作废的读数与要重扫的表列出来，
  再让做决定的人点那一刀。本章的交付只是**把账准备好**（`scripts/acceptance.py` 的三套库对照
  ＋ 逐条差异），不替人做决定。
- **被否掉的选项及否掉的理由**：
  - 直接迁（「反正读数更好」）：七章的数字会同时失真，而**失真的数字不会报错**——
    它们只会继续被人引用；
  - 不量就迁：差值小于 1/n 时根本判断不了好坏，等于把决定交给印象；
  - 把迁移做成「先迁一小部分」（半迁状态）：两套切法的片混在一个库里，
    候选集与读数都再没有基准，出错时查不出是哪一侧。
- **失效线（什么条件下该推翻它）**：迁移的差值**小于 1/n** 时直接放弃（不值得做）；
  大于时走发布流程（重取基线 → 重扫阈值 → 更新受益章节的正文数字）。
  语料规模或解析器集合变化后，这条路要**重新量一次**再决定，不能沿用这一次的差值。
